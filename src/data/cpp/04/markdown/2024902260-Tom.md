## Overall

"Deep Space Echo" is a three-chapter narrative RPG set in a post-collapse world where the player character ECHO uncovers the truth across a Neon Ruins, a Deep-Web Forest, and an Abandoned Mainframe Vault. The architecture is genuinely impressive — an abstract Item hierarchy with Prototype clone(), a loot tracker, and three named endings that diverge based on choices made across all three chapters. The main rough edge is a single 103-line bag handler that could be split, and a lowercase `character.hh` filename that stands out against all the other headers.

**Operator Overloading — 10 / 10**

**Heap / Dynamic Memory — 10 / 10**

## Bonus

**Bonus score: 9 / 10**

Three named endings that actually diverge based on choices you made across three chapters — that's a real narrative design, not just a win/lose flag. The Memory Fragment threading through the whole run and then mattering at the exact right moment in the finale is genuinely satisfying to experience.

The rollback mechanic on Logic Tyrant (boss progress undone by certain choices) is the kind of thing you only put in when you care about how the game feels. The loot summary after each run showing items found vs. possible maximum is a small touch that gives it a proper roguelike finish.

**Clean Code note:** The architecture here is genuinely solid — anonymous namespace enums for BattleAction and StoryChoice, the Prototype clone() pattern for polymorphic Inventory deep copy, an abstract Item hierarchy with WeaponItem/PotionItem/ArmorItem, and std::map for loot tracking all show real design discipline. The main rough edge is handleBagAction() stretching to ~103 lines — everything else is cleanly decomposed into focused, well-named functions. Naming is consistent and expressive throughout, with the one quirk of the lowercase character.hh filename standing out against all the other headers.
