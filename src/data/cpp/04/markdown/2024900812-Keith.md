- **showMainMenu() at ~35 lines** (−2) — inlines display, input handling, and switch dispatch; splitting printMenu() from handleMenuChoice() would improve focus

  A function that displays a menu, reads input, and dispatches all three choices can only be tested by feeding it actual input — splitting display from dispatch lets you verify the menu renders correctly without simulating user interaction.

  ```cpp
  // GameManager.cpp:141 — showMainMenu() handles display, input, and all dispatch in one function
  void GameManager::showMainMenu() {
      // display the menu box (lines 144-155)
      std::cout << "Please select an option: ";
      int choice = getValidInput(1, 4);  // reads input inline
      switch (choice) {                  // and dispatches inline
          case 1: player->displayTeam(); break;
          case 2: std::cout << player->getInventory(); break;
          case 3: startArenaChallenge(); break;
          case 4: isRunning = false; break;
      }
  }
  ```

- **Heal loop hardcoded to 10 iterations** (−3) — `for (int i = 0; i < 10; ++i)` to find team members instead of using team size

  A loop capped at 10 will silently skip healing any team members beyond index 9 if the team ever grows — and a team smaller than 10 will call `getCharacter()` with out-of-bounds indices that must be guarded against inside the function.

  ```cpp
  // GameManager.cpp:124 — heal loop iterates to 10 regardless of actual team size
  for (int i = 0; i < 10; ++i) {
      Character* c = player->getCharacter(i);
      if (c) {
          c->heal(c->getMaxHP());
      }
  }
  // Should use player->getTeamSize() as the bound
  ```
