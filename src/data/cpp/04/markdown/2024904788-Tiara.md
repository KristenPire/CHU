**Heap / Dynamic Memory — 7 / 10**
- Game owns raw `Apostle*` pointers (`worldApostle`, `row1`, `row2`); `~Game()` correctly deletes all of them; `initApostles()` also cleans up before re-populating.
- **Rule of Three violated** (−3) — Game defines `~Game()` but no copy constructor or copy-assignment; any copy of Game would double-free all owned Apostle pointers

  Once `~Game()` deletes `worldApostle` and the row vectors, any other copy of that `Game` object will try to delete the same pointers again — the second deletion is undefined behaviour that typically produces a heap corruption crash.

  ```cpp
  // Game.cpp:14-18 — destructor deletes raw pointers; no copy ctor or copy-assign defined
  Game::~Game() {
      delete worldApostle;
      for (Apostle* ap : row1) delete ap;
      for (Apostle* ap : row2) delete ap;
  }
  // Missing: Game(const Game&) and Game& operator=(const Game&)
  ```

**Inheritance — 9 / 10**
- `Character → Apostle` (abstract: pure virtual `startTrial(Player&, View&)`) → Emperor, Pope, Empress, Lovers, World; `Character → Player` with essence-based stat computation; `currentApostle->startTrial(player, view)` drives the entire game loop — runtime polymorphism is central
- Virtual destructor on Apostle; `override` used correctly on all five subclasses; no object slicing
- **Latent bug** (−1) — Player hides (does not override) `Character::getATK()/getDEF()/getMaxHP()` since they are not declared virtual; `Apostle::attack(Character& target)` calls `target.getDEF()` via `Character&`, bypassing Player's essence-based computation — a design gap that could cause incorrect stat values

  When a method is not declared virtual in the base class, calling it through a base-class reference always invokes the base version — so `Apostle::attack(Character& target)` ignores all of Player's essence bonuses when computing damage, silently making the player weaker than their stats suggest.

  ```cpp
  // Player.cpp:11-21 — getATK/getDEF/getMaxHP are defined but NOT declared virtual in Character
  int Player::getATK() const {
      int total = essence[0] + essence[1] + essence[2] + essence[3];
      int avg = total / 4;
      return baseAtk + avg;
  }
  // Apostle::attack(Character& target) calls target.getDEF() via Character& reference
  // → Character::getDEF() is called, not Player::getDEF(); essence bonuses are lost
  ```
