- **Style issues** (−3) — `#define` macros for ANSI color codes instead of `const std::string` constants (bypasses the type system); `using namespace std` in Game.cpp; Chinese debug comment "绝不报错" left in the final submission

  Preprocessor `#define` macros have no type, no scope, and no namespace — they cannot be passed to functions, stored in variables, or debugged through a type error, unlike `const std::string` constants which behave as normal C++ objects.

  ```cpp
  // Game.cpp:13-18 — #define macros for color codes; debug comment left in submission
  // ========== 颜色全部回来！绝不报错 ==========   ← debug annotation in final code
  #define CLR_RESET   "\033[0m"
  #define CLR_RED     "\033[31m"
  #define CLR_GREEN   "\033[32m"
  #define CLR_YELLOW  "\033[33m"
  #define CLR_BLUE    "\033[34m"
  // preferred: const std::string CLR_RESET = "\033[0m";
  ```
