  A const/non-const signature mismatch means the friend declaration in the header names a function that is never actually defined — calling `operator<<` on a `const Inventory` would produce a linker error at runtime.


  If a `Player` or `NPC` is ever deleted through a `Character*` — which is natural if you store them in a polymorphic container — the derived destructor will not run, which is undefined behavior and can leave resources unreleased.
