- **No private member naming convention** (−4) — snake_case used (name, hp, max_hp) but no prefix distinguishes members from locals across all classes

  Without a prefix like `_` or `m_`, the reader cannot tell at a glance whether `hp` in a method body refers to a parameter, a local variable, or the class member — the compiler can tell them apart, but humans reading the code must trace the scope chain every time.

  ```cpp

      int hp;
      int max_hp;
      int atk;
      int def;
  ```

- **Inventory::items as raw pointer to heap vector** (−1) — `std::vector<Item>*` adds ownership complexity with zero benefit; `std::vector<Item>` by value is simpler and equivalent

  A heap-allocated vector requires a Rule of Three implementation (copy ctor, copy-assign, destructor) that `std::vector` by value provides automatically for free — the pointer adds manual ownership work without giving you anything a value member couldn't do.

  ```cpp
  // Inventory.cpp:3 — vector allocated on heap unnecessarily
  Inventory::Inventory()
  {
      items = new std::vector<Item>();
  }
  // copy-assign, destructor all manually manage this pointer
  ```
