  A public data member is a broken abstraction — any code anywhere in the project can modify the inventory without going through any validation or notification, making the Inventory class impossible to reason about in isolation.

  ```cpp
  // Game.cpp:453 — getPotionCount() reaches directly into inventory.items

  {
      return std::count_if(
          inventory.items.begin(),    // items is public — bypasses the Inventory interface
          inventory.items.end(),
          [&potionName](const Item& item) {
              return item.getName() == potionName;
          });
  }
  ```
