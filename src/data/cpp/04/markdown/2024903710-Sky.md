  When `getMaxHP()` is absent, any code that needs to display or use the maximum HP — including operator<< — must either hardcode the value or skip it; a hardcoded `"40"` will silently show the wrong max HP if the character is ever constructed with a different starting HP.

  ```cpp

      os << c.getName() << " | HP: " << c.getHP() << "/" << "40"
         << " | ATK: " << c.getATK() << " | DEF: " << c.getDEF();
      return os;
  }
  ```

- **battleLoop() mixes display with game flow** (−3) — `cout << m_hero`, `cout << m_inventory` inline; should delegate to showStatus()

  Embedding display output directly in the game-flow loop means that changing how stats are shown requires modifying the loop itself rather than a dedicated display function, coupling concerns that should be independent.

  ```cpp
  // Game.cpp:29 — display and flow logic both in battleLoop()

      while (!m_gameOver) {
          cout << "==============================" << endl;
          cout << m_hero << endl;           // display mixed into flow

          cout << m_inventory << endl;
          playerTurn();
          if (m_gameOver) break;
          enemyTurn();
          checkEnd();
      }
  }
  ```
