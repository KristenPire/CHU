- **explore() at ~40 lines** (−1) — extracting handleBossEncounter() would focus it; battle() takes Enemy by value causing an unnecessary copy on every fight (should be Enemy&)

  Passing `Enemy` by value to `battle()` constructs a full copy of the enemy object on every call — this is wasted work, and if Enemy ever becomes expensive to copy (e.g., gains a vector of moves), the overhead silently grows.

  ```cpp
  // game.cpp:145 — battle() takes Enemy by value, making a copy every fight
  void Game::battle(Enemy enemy)
  {
      while (player_.isAlive() && enemy.isAlive()) {
          Display::showBattleScreen(player_, enemy, !enemy.isBoss());
          // ... all mutations happen on the local copy, which is fine functionally
          // but Enemy& would avoid the copy at zero cost
      }
  }
  ```
