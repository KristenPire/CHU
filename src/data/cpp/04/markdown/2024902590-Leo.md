**Inheritance — 1 / 10**

- **No virtual methods, no virtual destructor, no override** (−4) — Character has no virtual destructor; undefined behavior if Player were ever deleted via Character*

  A base class without a virtual destructor means that deleting a derived object through a base pointer only calls the base destructor — the derived class's destructor never runs, which leaks any resources the derived class owns and is undefined behavior in C++.

  ```cpp

      Character(const std::string& name, int hp, int atk, int def);
      // ~Character() not declared; compiler generates non-virtual one
      // If Player* is ever stored as Character* and deleted, UB

  ```
