- **Canonical Form** (−4) — `Game` owns raw pointers (`player`, `vector<Room*>`) but defines only a destructor — no copy constructor or copy-assignment, violating Rule of Three; same violation on `Room` which owns a `Character*`; any copy would cause a double-free

  The Rule of Three exists because when a class owns heap memory, the compiler-generated copy operations blindly copy the pointer — two objects then believe they own the same allocation, and both will try to delete it on destruction.

  ```cpp
  // include/Game.hh:38-40 — raw owning pointers, destructor only
  Character* player;
  Room* currentRoom;
  std::vector<Room*> rooms;
  // ~Game() defined (calls cleanup()), but no copy ctor or copy-assign
  ```

- **Magic numbers** (−4) — `10000` as "infinite damage" in flee (Game.cpp:173), exp and level-up values, MP costs, and `cin.ignore(1000)` scattered throughout with no named constants; Chinese development comments left in final build (Game.cpp:35, 98-102); `displayMainUI()` and `displayCombatUI()` share a near-identical 30-line header block with no extraction

  A magic number like `10000` for "deal fatal damage on flee" is invisible in context — a reader seeing it has no way to know it means "guaranteed kill" without reconstructing the intent from surrounding code.

**Heap / Dynamic Memory — 8 / 10**
- Raw pointer mode: `Game` allocates player and rooms; `cleanup()` deletes both; all new/delete pairs match
- **Rule of Three violation** (−2) — `Game` and `Room` both own raw pointers with a destructor but no copy constructor or copy-assignment; any accidental copy causes a double-free

  C++ will synthesize a copy constructor that copies the pointer value — two objects then share ownership of the same allocation and both will call `delete` on it when destroyed, causing undefined behavior.

  ```cpp
  // include/Game.hh — destructor declared, but no copy ctor or copy-assign
  Game();
  ~Game();          // defined — calls cleanup()
  void run();
  // (no Game(const Game&) or Game& operator=(const Game&))

  // src/Game.cpp:14-19 — cleanup() deletes player and all rooms
  void Game::cleanup() {
      if (player) delete player;
      for (Room* r : rooms) delete r;
  }
  ```

**Inheritance — 0 / 10**
