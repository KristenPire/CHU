## Overall

"The Fox Knight's Expedition" is a full-featured RPG with three playable professions, branching routes, a shop, skill leveling, an equipment system, and four distinct endings — including a hidden goose subplot that earns its own ending. The 20-file modular architecture with dedicated subsystems (BattleSystem, EventSystem, ShopSystem) and a clean ICombatant/IResourceUser interface hierarchy is genuinely impressive. The main structural weakness is that the game's entire narrative flow lives inside a single 181-line `run()` function in Game.cpp, undercut further by `goto` labels and inline hardcoded enemy stat literals.

- **run() is 181 lines with `goto` labels** (−5) — entire game narrative, route choices, enemy definitions, and ending text inlined in one function; `goto ENDING` and `goto PLAY_AGAIN_PROMPT` are C-style anti-patterns in C++

  `goto` jumps bypass local variable construction and destruction in the code between the jump and the label, and they make control flow impossible to follow by reading top-to-bottom — a reader must mentally trace every possible jump to understand what state is live at any given point.

  ```cpp
  // ... 130+ more lines ...
  ENDING:
      if (!player.isAlive()) { /* ending text */ goto PLAY_AGAIN_PROMPT; }

      int again = readIntInRange(1, 2);
  ```
