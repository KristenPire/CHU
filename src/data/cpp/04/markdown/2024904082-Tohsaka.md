## Bonus

**Bonus score: 7 / 10**

The rest system is the best part of the design — you can heal, but there's a 30% chance the rest triggers an ambush where the enemy gets a free hit first. That one mechanic makes every non-combat turn a real choice. The crit system and the flee penalty (drops you a floor) add texture without overcomplicating things.

The boss floor setup ("THE AIR GROWS HOT. THE DEMON LORD APPEARS!") is a nice moment.

**Clean Code note:** Most of the code is well-structured — the function decomposition above startBattle() is solid and naming is consistent throughout. The two things to fix: break startBattle() into smaller pieces, and pull the magic numbers out into named constants at the top of Game.cpp. MAX_FLOORS already exists as a constant, so the pattern is there — just needs to be applied to the rest.
