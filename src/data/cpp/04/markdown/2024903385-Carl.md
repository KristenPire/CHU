## Overall

"Knight's Road" is a complete, honest dungeon crawler: three floors of increasing difficulty (Bat, Zombie, Ancient Dragon), a shop, a level system with crit mechanics, and a clean top-level flow. ## Bonus

**Bonus score: 5 / 10**

The critical hit mechanic — 1-in-5 for the player, 1-in-10 for enemies — is a small design detail that gives the combat genuine unpredictability without overcomplicating it. The asymmetry feels intentional and it works.

The three-floor progression (Bat → Zombie → Ancient Dragon) gives the game a proper arc, and the flow from run() through menu() and battle() to nextFloor() is clean and easy to follow. It's a complete, honest project that does exactly what it says it does.

**Clean Code note:** The top-level structure is clean and readable — run(), menu(), shop(), nextFloor(), and battle() each have a clear job. The main thing to address is the duplicated item-use block that appears verbatim in both menu() and battle(): extracting that into a shared useItemFromInventory() function would halve that code and make both functions shorter. Adding named constants for the stat values (enemy HP, player starting stats, floor thresholds) would also make the code much easier to tune without hunting through the function bodies.
