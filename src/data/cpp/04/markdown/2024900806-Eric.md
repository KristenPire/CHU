## Bonus

**Bonus score: 18 / 10**

Stealing time from the wealthy to redistribute to the poor is a genuinely original concept — it's thematically distinct from every other dungeon crawler in the batch, and the box-drawing UI in displayUI() shows real care for how the game looks in the terminal.

The sword vs. bow distinction (flat bonus vs. random range) is a small design choice but a meaningful one — it gives the combat options actual character. And `// ⭐ 清掉换行（关键）` is exactly the kind of comment someone writes at 2am when something finally works.

**Clean Code note:** The structure is clean at the top level: run() sets up and delegates to combat(), displayUI() handles presentation separately — that division is solid. The main readability issue is that all the magic numbers (player HP=20, ATK=5, DEF=2; sword +3, bow +2; enemy HP=60) live directly in run() and combat() without named constants, which makes the code harder to adjust. Adding a few constants at the top of Game.cpp would make the game much easier to balance and read.
