- **Confusing direction-to-job mapping** (−1) — `getHeroJobFromChoice()` reuses direction enum values (South=2 for Mage, West=3 for Tank) to select hero job; a separate `JobChoice` enum would be cleaner

  Reusing an enum intended for cardinal map movement to mean something entirely different (hero class selection) is a hidden semantic trap — any reader of this code who sees `GameConstants::South` in `getHeroJobFromChoice()` has no way to know it means "Mage" without tracing the call chain.

  ```cpp
  // Game.cpp:52 — direction enum values repurposed for job selection
  Hero::Job Game::getHeroJobFromChoice(int choice) const
  {
      if (choice == GameConstants::South)   // South = 2, but here means Mage
          return Hero::Job::Mage;
      if (choice == GameConstants::West)    // West  = 3, but here means Tank
          return Hero::Job::Tank;
      return Hero::Job::Warrior;
  }
  ```
